# 课程筛选细则（公开版 · 已脱敏）

用于判断"用户给的这门免费课程/证书，值不值得发一篇笔记"。

> 本文为简体中文：本 skill 面向中文平台（小红书）创作者，属受众定位而非语言限制。

## 1. 通用爆款公式（2026-09-13 修订）

> **【出品方】+ 结果感动词 + 时长 + 凭证类型(证书>徽章) + 附加钩子(答案/模板/保姆级)**
>
> ⚠️ 旧公式「0元/免费+拿证」已废弃：9/12 两次实测「白嫖/0元/免费」触发软限流，「免费+官方+拿证」组合触发营销标签。此处的「免费/拿证」是**筛课价值判断**（判断这门课值不值得做），**不是发布文案用词**——发布文案见 SKILL.md Step 4 的新公式，禁用词已列全。

## 2. 品牌分级

| 级别 | 代表 | 判断 |
|------|------|------|
| T1 强背书 | 微软×LinkedIn / Google / OpenAI / 哈佛等世界名校 | 优先，受众认知零门槛 |
| T2 中背书 | HubSpot / Kaggle / Cisco / IBM / 阿里云·腾讯云·华为云 | 可发，需搭"岗位关联"卖点 |
| T3 弱背书 | 小众 AI 创业公司、国内认知度低的海外厂 | 谨慎，除非课程本身极稀缺 |

## 3. 验证清单（8 项，逐项核实）

| # | 检查项 | 怎么核 | 不过关的后果 |
|---|--------|--------|--------------|
| 1 | **真免费？** 无 Premium/订阅/7天试用陷阱 | 官网注册页走一遍 | 评论区翻车=信任崩塌 |
| 2 | 时长是否 ≤1 天（最好 ≤6h） | 官方标注 or 抽查课程目录 | "4h"是钩子，太久劝退 |
| 3 | 给的是**证书还是徽章** | 完成页说明 | 徽章价值弱一半，标题都难写 |
| 4 | **可挂 LinkedIn / 简历 / 写进执照栏** | 证书页"Add to profile"是否存在 | 决定"能写简历上"卖点成立与否 |
| 5 | **有无改版/截止/限时**（紧迫钩子） | 官方公告、页面 Notice | 有=免费送紧迫感文案 |
| 6 | 零基础可学？无需代码？ | 课程描述/受众标注 | 决定受众盘子大小 |
| 7 | 学员数佐证（≥几十万更好） | 课程页 learner 数 | 封面可写"XX 万人已学" |
| 8 | 语言/访问门槛（英文？科学上网？） | 页面语言、注册地区限制 | 影响评论区预备问答 |

> 实操铁律：**发文前自己完整走一遍流程**——验证"还免费"+截图素材+记下测验答案。政策随时变。

|----|------|------|
| 真免费无陷阱 | | |

| 证书(非徽章) | | |
| 可挂 LinkedIn | | |
| 有改版/截止钩子 | | |
| 零基础 | | |
| 品牌 T1/T2 | | |

| **总分 (/8)** | | |

结论阈值：
- **≥6.5 发**（主力选题）
- 4.5–6.5 缓发（补强钩子后发，或当系列第 N 篇）
- <4.5 不发（理由写清，换候选）

## 5. 失败案例归因（泛化模板）

爆款公式缺一项都可能掉量。常见的失败模式：

- **缺"拿证"承诺**：用户心智里证书能写简历，徽章像参与奖 → 标题只能写"学习"无法写"0元+拿证"
- **小众品牌**：国内认知度弱 → 即便课程内容好也难匹配"0元拿证"心智
- **封面与标题时长不一致**：信任感打折
- **缺附加钩子**：无答案/模板/保姆级承诺，与"工具盘点"等同质化
- **纯通识无职业关联**：学完能干嘛不具体，弱化决策动力

**反向清单**：证书称谓要用足；品牌选大厂；标题封面时长统一；正文给步骤、封面给收益；钩子放最后一行或评论区。

## 6. 选题源（按需自核）

- 头部课程平台 Skillshop / LinkedIn Learning / Coursera FA / edX 审计 / HubSpot / Kaggle
- 大厂培训：微软 Learn / Google Cloud Skills Boost / Anthropic / OpenAI Academy
- 国内：阿里云 ACA / 腾讯云 / 华为云 官方训练营
- 筛选方式：直接搜"2026 free certificates / 免费证书 推荐"取交集，按品牌分级+打分表过滤
